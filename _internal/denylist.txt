# NOTE — pourquoi « _internal/ » ne figure PAS dans cette liste
# Le nom du dossier n'est pas un secret : le .gitignore public le

# fichiers internes, appliquée par le contrôle de chemin du hook
# (étape 2), qui est le bon mécanisme. Mettre « _internal/ » ici
# bloquerait toute documentation qui mentionne le dossier.

# Les fournisseurs sont N2. Un site statique doit néanmoins porter

# préfixe @runtime-ok: sur le motif concerné.
